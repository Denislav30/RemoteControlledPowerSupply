# Tests

This directory contains all test files for the ventilation control system, including unit tests, integration tests, and hardware validation tests. Testing ensures reliability and correctness of the system components.

## Contents
- Unit tests for individual modules
- API endpoint tests
- Database integration tests
- Hardware interface tests
- End-to-end system tests

## Running Tests
Use the appropriate test runner for each component (e.g., pytest for Python, Jest for JavaScript). Ensure test environment is properly configured before running.
