# Frontend

This directory contains the web dashboard implementation for remote monitoring and control of the ventilation system. It provides a responsive interface for viewing real-time temperature data, adjusting thresholds, and manually controlling the fan.

## Technologies
- React/Vue.js web framework
- Real-time data visualization
- Responsive design for mobile and desktop

## Features
- Live temperature monitoring with charts
- Manual fan control override
- Threshold configuration forms
- Historical data viewing
- System status indicators
