# Hardware

This directory contains low-level scripts, drivers, and configuration files for interfacing with the OLIMEX A20 board and MOD-IO module. It handles ADC readings from the analog thermometer, relay control for the fan, and I2C communication.

## Contents
- I2C communication scripts
- ADC calibration and reading utilities
- Relay control drivers
- Hardware setup scripts
- Safety check implementations

## Hardware Components
- OLIMEX A20 single-board computer
- MOD-IO expansion module
- Analog temperature sensor
- Relay-controlled fan system
- Voltage divider circuits
